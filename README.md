# .github

This repository contains default community health files for all Kr8.io organization repositories. These files provide consistent templates and guidelines across all our projects.

## What's Included

### Organization Profile
- **[profile/README.md](profile/README.md)**: The public-facing README that appears on the Kr8.io organization profile

### Community Health Files
- **[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)**: Our code of conduct based on the Contributor Covenant
- **[CONTRIBUTING.md](CONTRIBUTING.md)**: Guidelines for contributing to Kr8.io projects
- **[SECURITY.md](SECURITY.md)**: Security policy and vulnerability reporting procedures
- **[SUPPORT.md](SUPPORT.md)**: Resources for getting help and support

### Templates
- **[Issue Templates](.github/ISSUE_TEMPLATE/)**: Default issue templates for bug reports, feature requests, and questions
- **[Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md)**: Default PR template for all repositories

## Usage

These files are automatically used by all repositories in the Kr8.io organization that don't have their own versions. Individual repositories can override these defaults by creating their own versions.

## About Kr8.io

Kr8.io is focused on building tools and resources for Kubernetes and cloud-native development. Visit our [organization profile](https://github.com/Kr8-io) to explore our projects.
