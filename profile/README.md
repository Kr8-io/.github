# Welcome to Kr8.io

Kr8.io is an organization focused on Kubernetes (K8s) tools and resources for cloud-native development.

## 🚀 Our Projects

We build and maintain tools that make working with Kubernetes easier and more efficient. Our projects focus on:

- **Infrastructure as Code**: Tools and templates for managing Kubernetes clusters
- **DevOps Automation**: Streamlined workflows for deployment and operations
- **Cloud-Native Development**: Resources for building cloud-native applications
